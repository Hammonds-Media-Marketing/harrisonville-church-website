## Step 3: Select Principles, Then Write

**Always ground copy in at least one named principle from the vault.** After writing, annotate or summarize which principles were applied. This is mandatory — do not write copy that cannot be traced back to a behavioral science principle.

### Required Output Format

For every piece of copy, deliver:

1. **The copy itself** — clean, ready-to-use
2. **Behavioral science rationale** — bullet list of which principle(s) each element applies, with the study/source name
3. **Application notes** — where relevant, flag alternatives or tests the user could run (e.g., A/B test with vs. without anchor price)

## Behavioral Science Copywriting Principles — Quick Reference

Use these as a mental checklist before finalizing any copy:

**Messaging Architecture**
- [ ] Single core message (not multiple) — recall drops 35% with more than one
- [ ] Concrete and specific language — avoid jargon and vague descriptors
- [ ] No excessive exclamation marks
- [ ] Positive/hope-based framing over fear-based framing

**Attention & Hook**
- [ ] Used a Story Hook (Question, Unexpected, Irony, Relatable, Knowledge, or Secret)?
- [ ] Is there a Von Restorff distinction — something that makes this visually or linguistically distinct?
- [ ] Does the headline or subject line create an information gap the reader wants to close?

**Pricing & Value (if applicable)**
- [ ] Is there an anchor price? Is it placed strategically (highest first)?
- [ ] Is per-unit pricing included?
- [ ] Is there a decoy option in the pricing structure?
- [ ] Is any promotional element framed as a "gift" rather than a bundle?

**Social Proof & Authority**
- [ ] Is there a social proof signal — testimonials, statistics, trends?
- [ ] Is the testimonial a vivid story moment (not just "great service")?
- [ ] Is there an authority signal — expert endorsement, research citation, credentials?

**Persuasion**
- [ ] Is there a scarcity element (quantity, time)?
- [ ] Is there a small commitment that leads toward a larger one?
- [ ] Is there a reciprocity trigger (gift, value-first)?
- [ ] Does the customer feel like the Hero, with the brand as the Guide?

**Story Structure**
- [ ] Does the copy follow a recognizable arc (Man In A Hole, Rags To Riches, No Easy Way, or POPP)?
- [ ] Is there a "Movie Time" moment — a vivid, sensory detail that creates a visual simulation?
- [ ] Is the "Three Is The Magic Number" structure used where relevant?

## Common Errors to Avoid

- **Writing generic copy** and then reverse-engineering a principle — always start with the principle
- **Multiple core messages** in a single ad, email, or headline
- **Vague descriptors** ("innovative," "world-class," "cutting-edge") with no concrete proof
- **Fear-based framing** when hope-based framing is available
- **Bundle language** when "free gift" framing would reduce returns and increase perceived value
- **Ignoring tone calibration for voice/sales content** — new vs. returning customers require different energy levels
- **Storytelling without a structure** — every case study, testimonial, or brand story should map to a named arc
